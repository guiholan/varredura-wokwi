# varredura-wokwi

Multiplexação de displays de 7 segmentos com ESP32. Os segmentos de todos os dígitos compartilham os mesmos 7 pinos e o código liga um dígito por vez, trocando a cada 2 ms. Rápido assim, o olho vê todos acesos ao mesmo tempo.

Simulação: https://wokwi.com/projects/429774245058362369
